# 정답 검수

인자: 문제지 id 또는 파일 경로, (선택) 문제 번호 범위. 인자가 없으면 사용자에게 어떤 문제지인지 묻는다.

1. `data/worksheets-manifest.json`에서 id로 파일 경로를 찾는다.
2. `python -I scripts/validate_worksheets.py <파일>`로 스키마부터 확인(정답 미입력 목록 확보).
3. 대상 문제를 10문제씩 나눠 `math-checker`를 **한 메시지에서 병렬로** 호출한다. 50문제 이상이면 먼저 사용자에게 범위를 확인(비용·시간).
4. 결과를 합쳐서 `불일치`, `풀이 오류`, `판단 불가`, `정답 미입력`만 표로 보여준다. `일치`는 개수만.
5. 수정은 사용자가 승인한 항목만, 근거와 함께. `correct`는 0-based임을 다시 확인. 수정 후 검증 스크립트를 다시 돌린다.
6. 수정된 문제가 이미 학생들이 푼 문제라면, 기존 풀이 기록(Google Sheet)의 채점은 바뀌지 않는다는 점을 알린다.
